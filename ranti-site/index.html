Install in 1 minute

  1. Tap Download for Android above.
  2. Open the downloaded file. If asked, allow “Install unknown apps” for your browser or Files app, then tap Install.
  3. If Play Protect asks, tap More details → Install anyway.

First launch: 4 taps that matter

  1. Allow notifications, so reminders can reach you.
  2. Alarms & reminders: allow, so they ring on time.
  3. Autostart: switch Ranti ON (Xiaomi / Redmi / POCO).
  4. Battery saver: choose No restrictions for Ranti.
Ranti opens each of these screens for you on the last setup step, and again in Settings → “Make reminders reliable”. Use Send a test reminder there to check.
